# Roadmap

## 0.1 — offline foundation
- Runnable normalized-data module, synthetic examples, deterministic tests.
- Human-readable architecture, explicit scope and trust boundaries.

## 0.2 — integration pilot
- Pin a released Protocol 30-compatible Stellar SDK after validating its release notes.
- Add real testnet fixtures after the scheduled upgrade vote; record network and decoder versions.
- Integrate with an existing event indexer rather than duplicating one.
- Invite two maintainers to reproduce failure scenarios with sanitized exports.

## 0.3 — operational hardening
- Add database-backed checkpointing, bounded input sizes, and independent security review.
- Publish versioned schemas and packages after cross-repository contract tests.
- Validate performance and document failure recovery before production use.

No production deployment, audit certification, funding eligibility, or Drips approval is claimed.
